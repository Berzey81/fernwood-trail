# Fernwood Trail Co.

A custom WordPress theme created as a learning project.

## About the Project

Fernwood Trail Co. is a fictional outdoor adventure company. This project is being used to practice building a WordPress website from scratch without using a page builder.

The goal is to take a provided website design and recreate it as a custom WordPress theme while learning how WordPress themes, templates, and Gutenberg blocks work.

## Pages

The website includes four main pages:

- Home
- About
- Services
- Contact

## What I'm Learning

This project is helping me practice:

- Building a custom WordPress theme
- Using the WordPress template hierarchy
- Working with PHP templates
- Using `functions.php`
- Using `theme.json`
- Creating reusable WordPress components
- Working with the Gutenberg block editor
- Creating a custom Gutenberg block
- Managing a WordPress project with Git and GitHub
